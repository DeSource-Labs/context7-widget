# @desource/context7-widget-angular

## 0.1.0

### Minor Changes

- Released the core, Vue, Nuxt, React, Svelte, and Angular packages as one coordinated version with one shared Git tag
  and GitHub release.
- Initial release of native Angular bindings for `@desource/context7-widget`.
- Added a standalone, `OnPush`, signals-based component with typed inputs,
  outputs, controlled visibility, projected managed triggers, external trigger
  binding, and the complete widget interaction model.
- Added `provideContext7Widget` defaults and `Context7WidgetService` for
  reactive controls and browser-only programmatic mounting.
- Reused the core framework kit for conversation state, transport, Markdown,
  copy coordination, layout, modal behavior, defaults, and public types.
- Added strict template compilation, unit coverage gates, shared cross-browser
  E2E coverage, package validation metadata, and an Angular demo.

### Patch Changes

- Updated dependencies:
  - @desource/context7-widget@0.1.0
